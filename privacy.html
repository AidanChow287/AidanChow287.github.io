Clipper is a personal tool operated by Aidan Chow.

What it accesses. When the operator logs in with TikTok, the tool receives an access token that lets it upload videos to the operator's own TikTok account.

Where data is stored. The access token and all videos are stored only on the operator's own computer. Nothing is sent to any server owned by the operator.

What it does not do. It does not collect personal information from other people, does not sell or share data, and does not use data for advertising.

Deleting data. The operator can disconnect the tool at any time by deleting the saved token file and by removing the app's access in TikTok's account settings.
